# 권서연 — 개인 홈페이지 (커밋로그)

## 목적
현재의 저에게 동기부여를 해주고, 미래의 저에게 보여주기 위한 개인 홈페이지입니다. 또한 저의 가장 큰 후원자이신 부모님에게 제가 지금까지 어떤 마음으로 무엇을 이루어 왔는지를 증명할 증거물이기도 합니다. 관심 분야·활동·목표·프로젝트를 기록해 나갈 예정이며, 제 전공(Social Science & AI 융합학부)과 공부 중인 파이썬을 살려 개발 환경(터미널·코드 에디터) 컨셉으로 만들었습니다.

## 주소
- 공개 홈페이지: https://umggae.github.io/
- GitHub 저장소: https://github.com/umggae/umggae.github.io

## 실행·수정 방법
1. 저장소를 클론하거나 다운로드합니다.
2. `index.html`을 브라우저로 열면 바로 확인할 수 있습니다. (별도 설치·빌드 없음)
3. 내용을 고치려면 `index.html`(글·구조)과 `style.css`(색상·레이아웃)을 편집기로 열어 수정합니다.
4. 로컬에서 실제 배포 환경처럼 확인하려면 프로젝트 폴더에서 `python3 -m http.server`를 실행하고 `http://localhost:8000`으로 접속합니다.

## 현재 상태
- PC 화면과 휴대전화 화면(390px 기준)에서 가로 스크롤 없이 보이는지 확인했습니다.
- 이미지 10장에 대체 텍스트를 넣고, Tab 키로 이동할 때 포커스 표시가 보이는지 확인했습니다.
- 메뉴·링크·이미지·뜨개작품 갤러리·라이트박스가 모두 정상 작동하는지 확인했습니다.

**동료 의견과 반영한 점**
친구는 "과정을 글로 쭉 설명하는 것보다, 실제 결과물을 직접 볼 수 있게 하는 게 더 좋을 것 같다"고 조언했습니다. 따라서 이 의견을 반영해:
- 뜨개질 취미를 글로만 쓰지 않고, 실제로 만든 뜨개작품 사진 10장을 갤러리로 넣었습니다.
- 대외활동은 활동 당시 쓰던 인스타그램 계정을 직접 링크했습니다.
- 완성한 프로젝트(수업 과제로 만든 것 포함)는 GitHub 저장소 링크를 달아서, 설명만이 아니라 실제 코드를 볼 수 있게 했습니다.

**스스로 점검하고 고친 점**
다른 학생들 홈페이지와 비교해봤을 때 제 홈페이지가 너무 평범하고 심심해 보인다고 느꼈습니다. 그래서 전공(Social Science & AI)과 공부 중인 파이썬을 살려, UI 전체를 개발자의 작업 환경(터미널·코드 에디터) 컨셉으로 바꿨습니다. 관심 분야는 JSON 코드처럼, 활동은 git 커밋 로그처럼, 목표는 TODO 체크리스트처럼 보이게 다시 만들었습니다.

이후에도 화면을 직접 보면서 문제를 찾아 고쳤습니다.
- 처음엔 다크 모드가 너무 어두워서(완전 검정+흰 글씨) 눈이 피로해, 조금 더 부드러운 톤으로 바꿨습니다.
- 화면 속 명령어들이 제가 모르는 언어(bash)로 되어 있어 어색해서, 제가 실제로 배운 파이썬 문법(`>>> os.listdir()` 등)으로 바꿨습니다.
- 본문 글씨가 배경에 묻혀 가독성이 떨어지는 부분을 찾아 색과 크기를 조정했습니다.

**사용한 자료**
- 폰트: Pretendard, JetBrains Mono (Google Fonts)
- 아이콘: Lucide

**AI 도움**
Claude Code를 실제 코딩 도구로 사용했습니다. HTML/CSS 작성, 여러 디자인 시안(파스텔, 미니멀, 에디토리얼, 개발자 컨셉 등) 제작 등의 과정을 대부분 Claude Code가 실행했습니다.

제가 한 일은 다음과 같습니다.
- 제 전공(Social Science & AI)과 파이썬 학습 경험에 맞는 "커밋로그" 컨셉을 제안하고 시안을 직접 선택했습니다.
- 완성된 헤드라인·소개 문구가 마음에 안 들면 다시 써달라고 요청하고, 방향을 여러 차례 수정했습니다.
- 자기소개, 활동 서사, 프로젝트를 만든 진짜 계기(재테크 열풍, 참교육 드라마 등) 같은 실제 콘텐츠는 제가 직접 제공했습니다.
- 화면과 기능을 제가 직접 확인하고, 친구 피드백을 반영할 부분을 판단해 지시했습니다.
- 이 README도 초안을 받은 뒤 제 상황에 맞지 않는 부분(목적, 동료 의견과 스스로 고친 점의 구분 등)을 직접 다시 썼습니다.
