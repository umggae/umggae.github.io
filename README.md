# 2주차 개인 홈페이지 시작 파일

설치 없이 브라우저로 열 수 있는 HTML·CSS 예제입니다.

## 시작하기

1. 압축을 푼 `내_홈페이지` 폴더 전체를 코드 편집기에서 엽니다.
2. `index.html`을 브라우저로 엽니다.
3. Claude Code에서 이 작업 폴더를 열고 수정할 내용을 요청합니다.
4. 파일을 저장한 뒤 브라우저를 새로고침해 결과를 확인합니다.

`index.html`에는 내용과 구조가, `style.css`에는 색상·크기·배치가 들어 있습니다.

## 첫 작업 요청 예시

> 이 폴더의 index.html과 style.css로 개인 홈페이지를 만들고 있어. 소개, 관심 분야, 프로젝트의 세 영역과 현재 메뉴를 유지해 줘. 이름은 [내 이름], 소개는 [직접 쓴 소개], 관심 분야는 [세 가지 관심 분야]로 바꿔 줘. 아직 완성한 프로젝트는 없으니 프로젝트 영역에는 준비 중이라고 표시해 줘. 새 파일이나 라이브러리는 추가하지 말아 줘. 수정 전에 계획을 짧게 설명하고, 수정 후 확인할 항목을 알려 줘.

대괄호 안에는 본인이 공개할 내용을 직접 작성합니다. 실제 이름 대신 별칭을 사용해도 됩니다. 비밀번호, 전화번호, 상세 주소 등 불필요한 개인정보를 적지 않습니다.

## 완료 기준

- 자기소개, 관심 분야, 프로젝트 영역이 모두 보입니다.
- 상단 소개·관심 분야·프로젝트 메뉴가 해당 영역으로 이동합니다.
- 프로젝트 보기 버튼이 프로젝트 영역으로 이동합니다.
- 프로젝트가 없다면 준비 중이라는 안내가 보입니다.
- 화면 너비 390px에서도 가로 스크롤이 생기지 않습니다.
- Tab 키로 링크를 이동할 때 현재 위치를 확인할 수 있습니다.

## GitHub 링크

현재 `GitHub 홈페이지` 링크는 실제로 열리는 `https://github.com/` 주소입니다. 학생은 본인 계정이 있다면 본인의 공개 프로필 URL로 바꾸고, 링크 문구도 `내 GitHub`처럼 알맞게 고칩니다. 계정이 없으면 현재 링크를 그대로 두거나 링크를 삭제해도 됩니다.

## 오늘의 범위

브라우저에서 작동하는 첫 버전까지 만듭니다. 온라인 배포와 Git 저장은 다음 주에 진행합니다. 예제에는 JavaScript, 외부 폰트, 외부 이미지, 설치 명령이 없습니다.
